# Survival presentation media

Unmodified pinned Mineclonia textures, identified in ../status_assets.json.
Armor media: Mineclonia license (see accompanying upstream LICENSE and armor
README). Heart: Mineclonia base textures, same upstream media license.
Hunger/exhaustion: accompanying mcl_hunger README credits PilzAdam, BlockMen
and Wuzzy and declares WTFPL for these textures. No gameplay Lua imported.

Original water droplet, sleep/moon, comfort/bandage and unavailable icons: CC0-1.0. Editable SVG sources and license in ../status-icons/. Their rasterized PNGs have checksums and reproducible conversion commands in the asset manifest.
