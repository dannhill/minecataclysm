# Static storage presentation

`models/mcl_chests_chest.b3d` and `textures/mcl_chests_normal.png` are copied
unchanged from the pinned Mineclonia `mods/ITEMS/mcl_chests` directory.
Their upstream notices and licenses are retained in the captured Mineclonia
sources; the shared Mineclonia license copy is in
`../cdda_items/media-notices/Mineclonia-LICENSE.txt`.
Only the static mesh and texture are used. No Mineclonia inventory, loot,
capacity, animation callback or container gameplay runs here.
