# Windows 11 x64 delivery — 2026-10-21

The generated local installer is `dist/windows11/Minecataclysm-Windows11-Setup.exe`
(294,522,012 bytes). Double-click installs for the current account, creates
desktop/start-menu shortcuts and starts the integrated game. Subsequent starts
use `Minecataclysm.exe` or the shortcut. No Bash, Python, WSL, SDK or administrator
installation is needed. The native GUI supervisor starts actual CDDA and Luanti,
using the accepted continuous 4x mode and English default; Italian remains WIP.

Saves/settings/logs live in `%LOCALAPPDATA%\Minecataclysm`, separate from
`%LOCALAPPDATA%\Programs\Minecataclysm`. Normal quit waits for CDDA's canonical
save. Update/uninstall preserve player data. The installer includes the native
executables, recursive DLL closure, game assets, catalogs, licenses, corresponding
application/dependency sources and an offline copy of the human testing ledger.
The installer is unsigned. The binary is a local build output, not a tracked Git
file or a published GitHub release/asset.
