# EXT-01 — External storage and partial collection

Scoped automated delivery, CWM 2.19, installed in ordinary `start.sh`.
Root source and complete fork patches were captured before builds.
Reconstructed and installed renderer flows each pass 31 checks, including
pristine-core canonical readback; manual acceptance remains PENDING.
[Machine-readable receipt](external-storage-evidence.json).

RMB on a nearby native CONTAINER furniture opens two nine-column grids.
Ground backpacks, counted stacks and multi-item piles open the same view.
Single ordinary loose items retain immediate pickup. Storage contents have no
rotating drops. Static chest art is a proxy for native furniture, including
lockers; native passability remains authoritative.

Drag external → owned receiving area to collect, owned → external receiving
area to deposit, or onto an actual container item to insert. Select a stack and
set Quantity before dragging it for a partial transfer. No local slot move is
committed. CDDA pickup/drop/insert actors pay costs, choose native pockets,
handle capacity/theft and persist canonical activity/state. Menu returns only
after native completion and paid clock credit.

Views bind absolute adjacent coordinates, avatar origin, terrain/furniture
identity, safe item_locations, parent chains and quantity/type state. Admission
and execution revalidate. Sealed, unperceived, distant and changed sites reject;
external entries cannot be equipped or arranged as owned items. Contents on
hidden/sealed tiles are excluded from ground exports.

Vehicle cargo, pouring, explicit per-pocket placement, opening seals and
multi-item batch transfer remain deferred. Native DROP retains its overflow
policy if the destination changes during the activity; actual outcome is
requeried, never inferred by the client. Full SAVE-001 remains OPEN and the
historical M5.5 conformance gate remains FAILED.

Manual checks are deferred in `docs/validation/pending-manual.md`.


Verification uses cached owned reconstructions, not a new clean-build or whole
conformance gate. Native suite: 178 cases / 185963 assertions (seed 42).
Luanti: 309 tests / 47 modules, plus 648 Catch assertions / four cases.
Protocol: ten tests; projection cache: empty storage, disappearance, rebasing
including negative Z and full clear. Actual renderer tests use private Xvfb,
real `start.sh`, isolated copied saves, typed quantity, drag input and a
byte-transparent relay for reconnection. Fresh-world execution and restart
readback (19 checks) retain counts, native parents and identity without replay.

The installed client/native hashes, catalogs, rollback paths, commands, source
identities, retained failed attempts and artifact hashes are recorded in the
receipt. Initial failures were API/test harness issues: native item_location
uses position(), Catch resets RNG on section entry, the fixture's closed door
redirected native item placement, a helper shadowed the select module, and
synthetic input was missed during concurrent GUI runs. The low sealed crate must be targeted below the tall locker eye level.
Successful serial runs retain physical drag, pause, resync and native checks;
no gameplay invariant was removed to make the checks pass.

Regression verification also passes: 40 installed held-RMB aim/ranged checks and
15 native-wire pickup checks. Default continuous scale remains 4; English and
Italian catalogs are unchanged. The isolated demo launcher passes copied-user,
private-world, private-port and continuous-mode checks. No personal save was
opened or modified for verification.
